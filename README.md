# cse210
This repository comprises code and projects created for my CSE 210 course.

This repository contains the starter code for many different projects. They are arranged as follows:

* `sandbox` - An empty project used as a template for future ones.
* `csharp-prep` - Each of the C# Prep assignments.
* `prepare` - Each of the preparation Learning Activities.
* `prove` - Each of the prove Developer projects.
* `final` - Final project.
